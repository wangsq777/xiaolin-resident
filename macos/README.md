# 小林驻留中 · macOS 动态巡逻站桌宠

一款围绕林家谦动态巡逻与日常陪伴设计的桌面宠物。

当前版本为 `v0.6.0`。这个目录保存已经完成并经过界面验证的 macOS 版本，同时保留早期 Swift/Xcode 原型。应用不会自动爬取 Instagram 或 Threads，而是陪用户亲自打开林家谦的官方主页、记录巡逻时间，并通过不同人物形象、关怀提醒和轻量互动安静地留在桌面上。

## 项目定位

“小林驻留中”不是社交平台抓取器，也不承诺自动发现新帖子。Instagram 与 Threads 缺少适合本项目的公开读取接口，因此当前产品选择了一条更简单、可靠的路径：

> 由用户决定什么时候出发，小林负责陪伴、记录和回应。

应用只打开预设的官方主页，不接触用户的社交平台账号和登录信息。

## 核心体验

### 动态巡逻站

关怀中心提供两个固定入口：

- [Instagram · @terencelam0903](https://www.instagram.com/terencelam0903/)
- [Threads · @terencelam0903](https://www.threads.com/@terencelam0903)

点击任一入口后：

1. 系统浏览器打开对应的官方主页。
2. 桌宠切换为“巡逻中”形象。
3. 8 秒后返回用户之前手动选择的状态。
4. 应用在本机记录该平台的上次巡逻时间和今日巡逻次数。

应用不会读取、复制或保存帖子内容。

### 手动状态

用户可以在“提醒 → 而家状态”中随时切换桌宠形象。

| 状态 | 陪伴表现 |
| --- | --- |
| 休息 | 安静看书，作为普通启动状态 |
| 工作 | 使用工作形象，陪用户进入专注状态 |
| 伤心 | 展开安慰小窗，显示拥抱形象和温柔回应 |
| 摸鱼 | 使用睡衣看手机的形象，陪用户放松一下 |
| 免打扰 | 保持低打扰状态，并覆盖普通互动 |

应用还会根据场景短暂显示巡逻、喝水、活动身体、护眼、睡眠和完成提醒后的开心形象。

### 伤心安慰模式

“伤心”不是一张静态状态图，而是一段克制的陪伴互动：

- 桌宠小窗会横向展开，完整显示拥抱形象与安慰文字。
- 人物以缓慢的“拥抱呼吸”动作轻微摇晃。
- 安慰语每 9 秒轮换一次，不弹系统通知，也不制造额外压力。
- 单击人物会立即换一句安慰，并出现一次轻微上浮的爱心。
- 双击人物仍然可以打开关怀中心。
- 开启系统“减少动态效果”后，相关动画会自动停用。

所有安慰语和互动逻辑都在本机运行，不调用网络服务或 AI 接口。

### 日常关怀

应用内置三类可配置提醒：

- 喝水提醒
- 久坐活动提醒
- 眼睛休息提醒

提醒出现时，可以选择完成、稍后提醒或今天不再提醒。完成提醒后，小林会短暂进入开心状态；关怀中心会记录当天各类提醒的完成次数。

安静时段支持跨午夜设置，例如 `23:00–08:00`。桌宠也会在夜间或长时间没有操作时进入睡眠状态。

## 窗口与操作

项目由两个互相同步的窗口组成：

- **关怀中心**：动态巡逻站、当前状态、关怀提醒和设置。
- **桌宠小窗**：始终置顶，显示人物形象、当前回应和提醒操作。

常用操作：

- 拖动桌宠空白区域可移动位置。
- 双击人物可打开关怀中心。
- 右键人物可快速切换状态或退出应用。
- 开启鼠标穿透后，桌宠不会拦截工作区点击。
- 关闭关怀中心只会隐藏主窗口，桌宠和系统托盘仍会驻留。

## 本地数据与隐私

- 只允许打开项目内预设的 Instagram 与 Threads 官方主页。
- 不使用第三方抓取服务，不需要社交平台 Token。
- 不保存账号密码、Cookie 或登录状态。
- 不读取或复制 Instagram、Threads 的帖子内容。
- 巡逻记录、关怀设置和提醒记录全部保存在本机。
- 不调用摄像头或麦克风。

## 启动开发版

需要 Node.js 22 或更高版本。

```bash
npm install
npm start
```

代码检查、自动化测试与界面检查：

```bash
npm run check
npm test
npm run smoke:ui
```

`smoke:ui` 会临时启动应用，检查主要人物状态、伤心安慰互动和核心界面，完成后自动退出。
