# 小林驻留中 · 关怀型桌宠

这是一个面向 macOS 与 Windows 的 Electron 桌宠。产品的后续定位是：通过克制的提醒、状态形象和本地化设置，为用户提供安静、有分寸的桌面陪伴。

当前 `v0.3` 已实现本地 BGM、双窗口桌宠和像素角色动画。BGM 将在后续版本中调整为可选能力，不再是桌宠运行的前提。关怀提醒、工作/休闲状态和角色素材切换尚待开发。

完整的产品方向、状态设计、任务优先级和验收标准见 [后续开发任务.md](./后续开发任务.md)。

## 当前版本使用方法

1. 打开项目中的 `BGM/` 文件夹。
2. 放入歌曲文件。
3. 启动应用；如果应用已经在运行，可在主页面点击“重新扫描”。
4. 在主页面点选歌曲，或者直接使用常驻桌宠上的上一首、播放/暂停、下一首。

支持格式：

- `.mp3`
- `.m4a`
- `.aac`
- `.wav`
- `.flac`
- `.ogg`
- `.opus`

推荐用下面的格式命名文件：

```text
林家谦 - 一人之境.mp3
林家谦 - 歌名.m4a
```

应用会把连字符前的内容显示为歌手，后面的内容显示为歌名。没有连字符时，完整文件名会作为歌名显示。

## 启动开发版

需要 Node.js 22 或更高版本：

```bash
npm install
npm start
```

检查代码和测试：

```bash
npm run check
npm test
npm run smoke:ui
```

## 两种窗口

- **BGM 管理页**：打开 BGM 文件夹、重新扫描、查看曲目和点歌。
- **桌宠小窗**：始终置顶，只显示拿吉他唱歌的小林、当前 BGM，以及上一首、播放/暂停、下一首三个按钮。

拖动小窗空白区域可移动。双击歌曲信息可打开 BGM 管理页；右键可以打开管理页、打开 BGM 文件夹或完全退出。

关闭管理页只会将它隐藏，桌宠仍会驻留。BGM 文件夹中已有歌曲时，下次启动默认只显示桌宠小窗。

## 后续产品方向

- 喝水、久坐和眼睛休息提醒
- 工作、休闲、临时提醒和夜间睡眠状态
- 不同状态对应不同像素角色形象
- 可设置的提醒间隔、安静时段、延后和今日跳过
- BGM 默认可关闭；只有启用时才显示音乐控制
- 所有状态和记录保存在本机，不调用摄像头或麦克风

## 本地与隐私

- 音频文件只在本机读取和播放，不会上传。
- 应用不会登录任何音乐平台。
- 不需要密钥、Token 或开发者会员。
- 请只放入你有权使用的音乐文件；应用本身不附带任何歌曲。
