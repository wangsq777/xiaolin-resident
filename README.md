# 小林驻留中 · 关怀型桌宠

这是一个面向 macOS 与 Windows 的 Electron 桌宠。产品的后续定位是：通过克制的提醒、状态形象和本地化设置，为用户提供安静、有分寸的桌面陪伴。

当前 `v0.4` 已实现关怀型桌宠最小可用版本（P0）：BGM 调整为可选功能，主页面改造为关怀中心，支持喝水提醒、安静时段、工作/休闲/免打扰状态切换，以及角色形象状态解析与默认回退。九种状态素材已经整理并接入映射，BGM 不再是桌宠运行的前提。

**P1 日常关怀扩展已完成**：新增久坐活动提醒、眼睛休息提醒、开心短暂态、今日提醒记录、提醒文案本地可配置、窗口位置/透明度记忆、鼠标穿透模式、系统托盘入口。

## 当前版本使用方法

### 关怀功能

1. 启动应用后会打开「关怀中心」主页面。
2. 在「当前状态」选择休闲 / 工作 / 免打扰，桌宠形象会随之变化。
3. 在「喝水提醒」「久坐活动提醒」「眼睛休息提醒」分别开启并设置间隔与稍后提醒时长。
4. 在「安静时段」设置不希望被打扰的时间段（支持跨午夜，如 23:00-08:00）。
5. 提醒出现时，桌宠小窗会展开气泡，提供「完成 / 稍后提醒 / 今天不再」三个动作。
6. 关怀中心底部展示今日各提醒完成次数。
7. 开启「鼠标穿透」后桌宠窗口不响应鼠标事件，适合放在工作区边缘。
8. 系统托盘常驻图标，右键可快速操作：打开关怀中心、显示桌宠、切换鼠标穿透、退出。

所有设置保存在本机，重启后仍然保留。

### BGM（可选）

1. 打开项目中的 `BGM/` 文件夹。
2. 放入歌曲文件。
3. 在关怀中心的「BGM 氛围音乐」开启开关。
4. 启用后在主页面点选歌曲，或直接使用常驻桌宠上的上一首、播放/暂停、下一首。
5. 如果应用已经在运行，可在主页面点击“重新扫描”。

BGM 默认关闭。关闭时桌宠小窗完全隐藏音乐控制按钮，只保留角色陪伴与关怀提醒。

支持格式：

- `.mp3`
- `.m4a`
- `.aac`
- `.wav`
- `.flac`
- `.ogg`
- `.opus`

推荐用下面的格式命名文件：

```text
林家谦 - 一人之境.mp3
林家谦 - 歌名.m4a
```

应用会把连字符前的内容显示为歌手，后面的内容显示为歌名。没有连字符时，完整文件名会作为歌名显示。

## 两种窗口

- **关怀中心**：状态切换、喝水提醒设置、安静时段设置、BGM 开关、角色素材状态。
- **桌宠小窗**：始终置顶，显示角色形象与当前状态文字；提醒发生时展开操作气泡；BGM 启用时显示音乐控制。

拖动小窗空白区域可移动。双击状态信息可打开关怀中心；右键可以打开关怀中心、打开 BGM 文件夹（启用时）或完全退出。

关闭关怀中心只会将它隐藏，桌宠仍会驻留。BGM 关闭时（默认），下次启动默认显示关怀中心；BGM 启用且有歌时，下次启动默认只显示桌宠小窗。

## 本地与隐私

- 设置、提醒记录和状态全部保存在本机。
- 音频文件只在本机读取和播放，不会上传。
- 应用不会登录任何音乐平台。
- 不需要密钥、Token 或开发者会员。
- 不调用摄像头或麦克风。
- 请只放入你有权使用的音乐文件；应用本身不附带任何歌曲。

## 目录

```text
BGM/                                用户放置本地歌曲的文件夹
后续开发任务.md                      关怀型桌宠产品规划与任务清单
src/main/main.js                    Electron 双窗口、关怀 IPC 与调度循环
src/main/care-store.js              本地关怀设置存储
src/main/reminder-scheduler.js      提醒计时器（可注入时钟、安静时段顺延）
src/main/character-resolver.js      角色状态解析器与素材回退
src/main/quiet-hours.js             安静时段判定（跨午夜）
src/main/bgm-library.js             BGM 扫描、文件名解析与安全路径校验
src/preload/                        安全 IPC 边界
src/renderer/index.html             关怀中心主页面
src/renderer/pet.html               桌宠常驻小窗
src/renderer/assets/                像素角色素材
src/renderer/assets/character-states/  角色状态形象
Scripts/prepare-character-assets.py    非破坏性整理用户提供的状态素材
tests/                              自动化测试
```

状态素材包括默认、工作、休闲、喝水、活动身体、眼睛休息、睡眠、完成回应和免打扰。透明 PNG 位于 `src/renderer/assets/character-states/`，用户提供的原图副本保存在其 `source/` 子目录。

早期 Apple Music / MusicKit 原型文件仍暂时保留作技术参考，但不会被当前应用加载或执行。
