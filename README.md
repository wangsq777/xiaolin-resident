# 小林驻留中 · 物料雷达桌宠

这是一个面向 macOS 与 Windows 的 Electron 物料雷达桌宠：集中整理林家谦的官方合作、活动和公开物料，同时通过克制的提醒与状态形象提供安静的桌面陪伴。

当前 `v0.5` 已将主页面改造成「物料雷达」：集中整理林家谦的官方合作、活动和公开物料，支持每日检查、来源状态、未读、收藏和外链查看。原有的关怀中心、桌宠状态、提醒和本地持久化继续保留。

**P1 日常关怀扩展已完成**：新增久坐活动提醒、眼睛休息提醒、开心短暂态、今日提醒记录、提醒文案本地可配置、窗口位置/透明度记忆、鼠标穿透模式、系统托盘入口。

完整的产品方向、状态设计、任务优先级和验收标准见 [后续开发任务.md](./后续开发任务.md)。

## 当前版本使用方法

### 关怀功能

1. 启动应用后会打开「关怀中心」主页面。
2. 在「当前状态」选择休闲 / 工作 / 免打扰，桌宠形象会随之变化。
3. 在「喝水提醒」「久坐活动提醒」「眼睛休息提醒」分别开启并设置间隔与稍后提醒时长。
4. 在「安静时段」设置不希望被打扰的时间段（支持跨午夜，如 23:00-08:00）。
5. 提醒出现时，桌宠小窗会展开气泡，提供「完成 / 稍后提醒 / 今天不再」三个动作。
6. 关怀中心底部展示今日各提醒完成次数。
7. 开启「鼠标穿透」后桌宠窗口不响应鼠标事件，适合放在工作区边缘。
8. 系统托盘常驻图标，右键可快速操作：打开关怀中心、显示桌宠、切换鼠标穿透、退出。

所有设置保存在本机，重启后仍然保留。

### 物料雷达

1. 启动应用后会打开「物料雷达」主页面。
2. 在来源状态中查看官方账号、官网和 X 来源的接入情况。
3. 使用「未读 / 收藏 / 合作 / 活动 / 物料」筛选快速定位内容。
4. 点击「查看来源」打开公开页面；点击星号可收藏，点击「标记已读」可清理未读数量。
5. 应用会每日自动检查；也可以随时点击「立即检查」。

首次启动内置的是产品演示资料，不代表真实活动。真实数据通过 `XIAOLIN_MATERIAL_FEED_URL` 接入一个返回 JSON 的授权 feed 聚合器；建议使用官方 API 或获得授权的数据源，不要在桌宠里保存 X 登录信息。

## 启动开发版

需要 Node.js 22 或更高版本：

```bash
npm install
npm start
```

检查代码和测试：

```bash
npm run check
npm test
npm run smoke:ui
```

## 两种窗口

- **关怀中心**：物料雷达、状态切换、喝水提醒设置、安静时段设置、角色素材状态。
- **桌宠小窗**：始终置顶，显示角色形象与当前状态文字；提醒发生时展开操作气泡。

拖动小窗空白区域可移动。双击角色可打开关怀中心；右键可以打开关怀中心、快速切换状态或完全退出。

关闭关怀中心只会将它隐藏，桌宠仍会驻留；下次启动默认显示物料雷达。

## 本地与隐私

- 设置、提醒记录和状态全部保存在本机。
- 物料收藏、已读记录和来源快照保存在本机。
- 应用不会登录 X，也不会把社交平台密码或 Token 写入物料数据文件。
- 桌宠用户不需要提供社交平台密码、Token 或开发者会员信息。
- 不调用摄像头或麦克风。
- 仓库内置的物料条目仅用于界面演示，不代表真实活动。

src/renderer/index.html             关怀中心主页面
src/renderer/pet.html               桌宠常驻小窗

状态素材包括默认、工作、休闲、喝水、活动身体、眼睛休息、睡眠、完成回应和免打扰。透明 PNG 位于 `src/renderer/assets/character-states/`，用户提供的原图副本保存在其 `source/` 子目录。

早期 Apple Music / MusicKit 原型文件仍暂时保留作技术参考，但不会被当前应用加载或执行。
